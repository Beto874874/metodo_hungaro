## Asignación óptima con el método húngaro — Avance 1

Programa en Python que resuelve problemas de asignación (agentes → tareas) con el
método húngaro y muestra cada paso del procedimiento.

## Cómo ejecutarlo

```bash
python hungaro.py           # resuelve las 3 instancias de ejemplo
python hungaro.py --pasos   # muestra las matrices de cada paso
python test_hungaro.py      # corre las pruebas automáticas
```

No necesita librerías externas (Python 3.8 o superior).


## Instancias incluidas

| # | Caso | Tipo | Resultado |
|---|------|------|-----------|
| 1 | 4 operarios × 4 máquinas (horas) | Minimizar | 49 h |
| 2 | 3 vendedores × 3 zonas (ventas) | Maximizar | 35 M$ |
| 3 | 3 repartidores × 4 pedidos, una ruta prohibida (km) | Minimizar, rectangular | 11 km |
